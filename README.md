# linkrot

Find dead links in your Markdown docs: concurrent link checker with Markdown and JSON reports. Zero dependencies.

## Features

- **Recursive scanning** of directories for `*.md` files, with `--include`/`--exclude` glob patterns (`.git/`, `node_modules/`, and `vendor/` are excluded by default).
- **Link extraction**: inline links `[text](https://...)`, reference-style `[text][ref]` + `[ref]: https://...` definitions, and bare `https://...` URLs in text. Code blocks and inline code are ignored.
- **Concurrent checking** via the stdlib `ThreadPoolExecutor`: `HEAD` first, automatic `GET` fallback when `HEAD` is rejected (405/403/501), one retry, per-request timeout, polite User-Agent.
- **Classification**: `ok` vs `dead` (4xx, 5xx, DNS errors, timeouts, connection errors). Redirects are followed and the final URL is recorded.
- **Reports**: Markdown report (dead-link table per file + summary) to stdout or `--report report.md`; `--format json` for machine-readable output.
- **Exit codes**: `0` = no dead links, `1` = dead links found, `2` = error.
- **Zero dependencies** — Python 3.9+ standard library only.

## Installation

```bash
git clone https://github.com/agenticspring/linkrot.git
cd linkrot
# No dependencies to install. Run directly:
python3 -m linkrot.cli /path/to/docs
```

Or add `linkrot/` to your `PYTHONPATH` and run `python3 -m linkrot.cli`.

## Usage

```
usage: linkrot [-h] [--include INCLUDE] [--exclude EXCLUDE]
               [--exclude-url EXCLUDE_URL] [--concurrency CONCURRENCY]
               [--timeout TIMEOUT] [--format {markdown,json}]
               [--report FILE] [--quiet] [--version]
               [path]

positional arguments:
  path                  directory (or file) to scan (default: current directory)

options:
  --include INCLUDE     glob for files to include (may be repeated; default: *.md)
  --exclude EXCLUDE     glob for paths to exclude (may be repeated)
  --exclude-url EXCLUDE_URL
                        regex for URLs to skip (may be repeated)
  --concurrency N       parallel requests (default: 10)
  --timeout SECONDS     seconds per request (default: 10)
  --format {markdown,json}
                        report format (default: markdown)
  --report FILE         write report to FILE instead of stdout
  --quiet               print only the report, no progress info
```

### Examples

Check the docs directory and write a Markdown report:

```bash
python3 -m linkrot.cli ./docs --report report.md
echo $?   # 0 = no dead links, 1 = dead links found, 2 = error
```

Machine-readable output for CI:

```bash
python3 -m linkrot.cli ./docs --format json --quiet
```

Typical CI usage (fails the build on dead links):

```bash
python3 -m linkrot.cli ./docs \
  --exclude-url 'localhost' \
  --exclude-url 'img\.shields\.io' \
  --concurrency 20 --timeout 15
```

Sample Markdown report:

```markdown
# Linkrot report

Scanned 12 Markdown file(s), 48 unique link(s) in 6.3s.
**Dead links: 2**

## docs/guide.md

| Line | Link | Status | Detail |
| --- | --- | --- | --- |
| 42 | [Old API](https://example.com/v1/api) | 404 | HTTP 404 |
| 87 | https://gone.example.net/page | — | dns error: ... |

_Generated by linkrot at 2026-10-16 07:10 UTC_
```

Sample JSON report:

```json
{
  "tool": "linkrot",
  "dead_links": 1,
  "files_scanned": 12,
  "links_checked": 48,
  "elapsed_seconds": 6.31,
  "dead": [
    {
      "file": "docs/guide.md",
      "line": 42,
      "url": "https://example.com/v1/api",
      "text": "Old API",
      "status": 404,
      "final_url": "https://example.com/v1/api",
      "detail": "HTTP 404"
    }
  ]
}
```

## Tests

```bash
python3 -m unittest discover -s tests -v
```

The test suite is self-contained: extraction tests need no network, and checker
tests run against a local `http.server` (live 200 vs 404 vs HEAD-rejected vs
connection refused vs `.invalid` DNS).

## Limitations

- Does not execute JavaScript — links rendered only at runtime by JS (e.g. SPA routers) are not detected.
- Does not solve CAPTCHAs or log in; sites behind bot protection may return false "dead" results — use `--exclude-url` for known-flaky hosts.
- Be respectful: keep `--concurrency` and `--timeout` reasonable against third-party hosts to avoid rate limiting.
- Bare URL extraction uses heuristics; exotic URL characters may be trimmed.
